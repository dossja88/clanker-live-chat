Respect `forget`, queue cancellation and privacy/schema invariants and do not publish viewer content into Git. - **Billing disabled; $0 added recurring costs**, no upgrades/trials/metered calls without explicit cost and owner approval. Distinguish a local engine checkpoint from durable storage, security against rollback, private hosting, network authenticity, uptime or actual Twitch game actuation. If specifically approved, use dedicated creator Google account/project-owned Restricted folder; never personal Drive, shared links, unauthorized uploads or automatic deletes. User-evaluated temporary previews are cleanup candidates **only after actual evaluation and preserved recovery path**, and require exact per-file owner deletion approval.

- Start with `node tests/regression.cjs` for changed browser/behavior code and `node scripts/run-offline-tests.cjs` for full relevant offline suites; require full final PASS summary **and exit 0** from actual Node when claiming test success. Simulated Twitch/EventSub, OAuth, visual browser, local game engine, headless games and live Twitch are different evidence levels. - Keep protected source, tested branch and source-blob identity, preserve all current public pages/robot assets unless specific scope. Verify only changed behavior, code + tests and final Git remote commit. If actual tool/runtime unavailable, report honestly, no fictional deployment.
