# Clanker AI — stream and character media rights preflight
**Scope:** Original Clanker gaming/VTuber project in this repository, not the separate Misread Machine educational channel. This is a planning/evidence gate only; no Twitch authorization, public stream, image generation, account changes, voice synthesis or game actions.

## Before committing to a stream, voice, clip or media feature
Inventory every new creative input and the **actual intended audience/distribution**, which may differ across (a) local offline simulation, (b) private owner preview, (c) public interactive Twitch broadcast, (d) monetized live/VOD/Shorts/clip distribution, (e) downloadable or redistributed source/asset pack.

| Asset/input | First-pass questions |
|---|---|
| Original R1 Clanker game avatar, expressions, screens and overlays | Who authored each image/animation/source? Is this exact project asset recoverable and free of copied logos or borrowed channel artwork? Separate educational Clanker and gaming Clanker files are **not** automatically cross-licensed |
| Synthetic/cloned/live voice and SFX/music | Exact engine, model/voice data, author/tool terms, commercial broadcast and VOD rights; no unapproved cloned identity, pre-existing song or ChatGPT Voice Output substituted into a commercial track |
| Game visuals, soundtrack and game publisher IP | Exact game's live-stream/recording and monetization policy, relevant music/licensing exceptions, brand/use limitations, platform rules and replay/clip redistribution rights; owning/playing a game alone does not clear all music rights |
| Twitch viewer messages/avatars, polls and personalized memory | Platform terms, user privacy/consent, retention, moderation and safe disclosure; **do not** expose private messages, tokens, viewer history or identifiers in public GitHub, clips or models |
| New third-party motion/VTuber tools, libraries and data | Dependency license/version, redistribution, backend service terms, security/OAuth scopes, free-usage/quota and whether the feature requires a commercial service |

## Required record for each materially new media input
`asset_id`, exact source/version/creator, `intended_use`, verified permission/link/date, rights restrictions and required credits, third-party components/likeness/branding, source hash if actual bytes exist, separate privacy/security effects, known free-service costs and `RIGHTS_HOLD` or `SCOPED_EVIDENCE_REVIEWED`. The latter means evidence is documented, **not** a legal guarantee, owner launch approval or successful real gameplay.

Review before spending time rendering/recording a new externally sourced input or connecting a new provider. A self-authored implementation can be designed/tested offline under existing scope, but added expressive assets, recordings and publishing still need rights and owner gates. If a publisher's rights to in-game music are unclear, mute/replace it with genuinely permitted original audio rather than assuming a general streaming permission covers it.

## Reuse and QA
Reuse unchanged verified original asset/voice/dependency records for identical use; reopen only when source/version, game title, account/terms, public monetization, clip/VOD format, marketing, or data-sharing use changes. Then inspect **real** voice, original avatar frames, actual game/source events and caption/sound consistency. Simulated Twitch tests, public Pages previews and green Node tests do not certify live platform rights, production identity or owner release.

Do not put private account evidence or unpublished media in this **public** repository. Record non-sensitive IDs and the status/opaque private receipt pointer only. No separate approval for stream/public channel use is granted here.
